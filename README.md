# Hello NN

My Neural Network Codes when I was beginner in Artificial Neural Networks

Clean, Commented, Single-Filed Python Programs + Jupyter Notebooks

## Prerequisites

The programs depend on the following dependencies:

* Python (3.5+)
   * Numpy (1.14+)
   * Matplotlib (2.0+)
   * Tensorflow (2.0+)
   * Jupyter Notebook
